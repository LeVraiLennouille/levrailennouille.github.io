# Lennouille - Portfolio UI/UX & Code

Voici le code source de mon portfolio professionnel hébergé sur GitHub Pages. Ce site démontre mon expertise en design d'interface et en développement web.


## La démarche technique

L'objectif de cette plateforme consiste à convertir les visiteurs en clients grâce à une interface ergonomique et des performances optimales. Le site est codé à la main, sans framework lourd.

- HTML5 sémantique avec balisage structuré.
- CSS3 basé sur une architecture Bento Grid.
- JavaScript natif pour les interactions.
- Intégration de balises JSON-LD pour le SEO local (Poitiers et Reims).
- Images optimisées aux formats WebP lossless et SVG.
- Site statique généré avec Jekyll, déployé via GitHub Actions sur GitHub Pages.
- Objectif de performance : un score Lighthouse de 90+.
